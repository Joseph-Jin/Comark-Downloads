**Both desktop companions require an iPad with the Comark iPad app from the App Store; they cannot be used on their own. The iPad app is not yet on the App Store.**

The files above are previews. Downloading a desktop package alone does not provide the complete product workflow. GitHub sign-in is not required to download.

### Mac preview

Unzip the archive to find ComarkMac.app. This build is not Apple-notarized and macOS may prevent it from opening. It is not a production installer. The Mac companion handles screen capture and annotated-image receipt from the paired iPad.

### Windows experimental receiver

Unzip and open Comark-Windows.exe. Select English or Chinese, enter a six-digit pairing code, and start the receiver. Detailed instructions are included in the ZIP.

This is an experimental receiving utility, not a complete Mac companion replacement. **Direct iPad-to-Windows pairing is not available in this build.** It is not digitally signed for Windows distribution.
